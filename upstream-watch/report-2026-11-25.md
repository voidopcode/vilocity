## Top PORT items

1. **fork: the newest in-game fixes for native's base** (`c96b4f2`, `a803c87`, `310c6eb`, `8dd30ab`, `a26859f`, `9376fd6`). These add the depth bounds test, so the first room is lit. Characters' textures get re-checked after streaming, which fixes the black face and pale hair. Packed textures stay in the upload queue. Writes through one view of a page are seen at its other views. Byte-copied descriptors are mirrored. The descriptor sync pass drops from 70–220 ms a frame to about 3 ms, and frames go from about 400 to about 230 ms. Native's base *is* the fork, so these should port the most cleanly. Port them in order.
2. **VIctory `0601955`: a helper lane's `v_readfirstlane` reads its own value.** This fixes a waterfall loop that ran to its limit in helper lanes and gave DEVICE_HUNG about 200 s into a retail world. Small change in `vilocity-shader/src/emit/lower.rs`.
3. **VIctory `ed0dbfd`: title writes under a busy shader-written range are copied.** It fixes stale sizes that made a dispatch loop until device removal. Also **`cd94d35` + `940d32f`: shaders mark the pages they write.** Copy-back then compares only those pages, where it used to compare 2.8–4.5 GB a frame (0.45–0.7 s of a 1.5 s frame). This is a big CPU-side win, but it touches `shadow.rs`/`watch.rs`/`descriptor/host.rs`, the same files the fork's view-guard work (`8dd30ab`) changes. Port the fork first, then merge by hand.
4. **xcl `c7f6933` (+ `2bea7ac`, `daf52ab`): heap memory windows moved off descriptors 0..1.** An empty T# read the 4 GiB window UAV as a texture, which gave DXGI_ERROR_DEVICE_HUNG. This is a compat hang fix.
5. **xcl `354ce0c`: `shaders --precompile --used-only`.** It builds only the pipelines the title used. On a 32-lane NVIDIA card a full pack takes hours; one test built 824 of 2,689 programs. This is the owner's GPU case.
6. **xcl `e591a8c`: compact form for huge repeating compute programs in direct DXIL** (4.3 MB → <0.5 MB). Also **`b937c33`: `-opt-disable debug-nops` for -O0 sources** (−22.7 % DXIL), and **`8c1faf1`: a CRLF-insensitive translator source hash.** That last one matters on Windows checkouts: without it, a cache of 2,689 translations was thrown away.
7. **VIctory `b58d198`: copies into title memory skip `VirtualQuery`** (about 2 ms per copy). **`4e60ea3`** drops unbuildable indirect calls before the clamp dispatch. **`9145d9d`** adds a stand-in window, so slow frames no longer turn into "Not responding" ghosts.

Path rules: xcl `crates/xcl/src/…` → `compat/crates/vilocity-compat/src/…` (`C/` below). VIctory/fork `crates/victory-X/…` → `native/crates/vilocity-X/…` (`N/X/` below). `apps/victory/…` → `native/apps/vilocity-native/…` (`main.rs` → our `lib.rs`). `XCL_*`/`VICTORY_*` → `VILOCITY_*`. Env var clash check: the fork's new switches (`HEAP_SYNC`, `VIEW_GUARD`, `PAGE_WRITES`, `LEVELS_ON_DEMAND`, `CARD_ROOM_*`, `HEAP_RECHECK`, `VIEW_OWN_COPY`, `REUPLOAD_WHEN_FULL`) and xcl's `DIRECT_COMPACT` are unused in both engines. `VILOCITY_RELAY`/`WIDE_BACK` already exist in native, and the fork's `c96b4f2` changes their defaults to on. That is intended.
